# 教学内容

本文面向作者；扩展开发者另见[教学扩展接口](TEACHING-EXTENSIONS.md)。本文适用于 MarkBridge 2.1.0-rc.1，其他版本的功能以对应 Release 文档为准。Markdown 与可视化编辑器仍维护同一份配对正文，阅读进度、播放状态和运行结果不写回文章。

## 先组织题意与解释

先用普通标题、段落、列表、公式和代码写出完整文章，再按阅读需要增加折叠与阶段。不要把只有运行组件才能看到的结果作为唯一题意或解答；无 JavaScript、打印及资源加载失败时，静态正文仍应完整可读。

在托管文章的区块插入器选择“折叠内容”，填写标题和默认展开状态，在内部继续插入正文区块。默认关闭只影响阅读展示，内部正文仍保存、可编辑。最多支持三层折叠；使用键盘可操作展开按钮，跳转到内部标题、脚注或段落评论时会先展开目标所属内容。

Markdown 使用完整、封闭的 v1 属性。每个教学块有文章内唯一的稳定标识，标题改名或顺序变化时保留该标识，不要使用标题或序号代替身份：

````markdown
:::mbb:v1 collapse {"id":"hint-one","title":"提示：先观察不变量","open":false}

先比较当前元素与前一个元素。行内公式 $a_i \leq a_{i+1}$ 和普通正文照常使用。

```javascript
const value = array[index];
```

:::mbb:end
````

标识为 1–64 个 ASCII 字母、数字、下划线或连字符，且以字母开头。重复标识、与已有 HTML 锚点冲突、空标题、未知属性、错误版本和超过嵌套上限会拒绝保存。代码围栏内的教学标记按代码保留；正文中的字面 `:::mbb:` 应转义开头的冒号。

## 将一篇文章分阶段阅读

插入“阶段导览”后，在其内部添加“阶段”，为每个阶段填写标题与稳定标识。题目、提示、推导、实现、拓展只是可选的课程安排，主插件不预设具体算法或阶段名称。一篇文章最多一个非空阶段组，只能位于正文顶层；阶段不嵌套，也不能放在组之外。阶段内部可使用折叠、代码对照及已有正文区块。

默认使用全文模式，也可在阶段组中选择分阶段模式。读者始终能切换到全文；全文会展开本篇折叠，但保留各代码组当前选择的语言；打印显示所有作者内容和所有语言版本。上一阶段、下一阶段与阶段选择保留原正文节点；目录、深链接和段落评论可跳到隐藏阶段，浏览器返回恢复阅读视图。点击继续只表示阅读导航，不表示学习完成，也没有服务器学习记录。

```markdown
:::mbb:v1 steps {"id":"array-lesson","title":"数组教程","mode":"staged","previous":true,"next":true,"full":true}

:::mbb:v1 step {"id":"problem","title":"题目"}

给定一组数字，请按升序排列。

:::mbb:end

:::mbb:v1 step {"id":"reasoning","title":"推导"}

先找出每轮操作保持的不变量，再分析比较与移动次数。

:::mbb:end

:::mbb:end
```

`mode` 只接受 `full` 或 `staged`；`full` 必须为 `true`。上一阶段与下一阶段按钮可分别设置，但不能隐藏全文入口。

## 对照两份教学代码

插入“代码比较”，分别填写左右标题、语言与原代码，再在内部补充重点解释。左右重点行分别按各自代码的行号填写，例如 `2,4,5`。空白、制表符、缩进和尾部换行都属于原代码，不会因差异显示被改写；源码缺少末尾换行时，编辑器提供明确的补换行操作，保存不会静默补齐。

````markdown
:::mbb:v1 code-compare {"id":"boundary-fix","leftTitle":"修改前","rightTitle":"修改后","leftHighlights":"1","rightHighlights":"1"}

```javascript
if (index <= array.length) {
  visit(array[index]);
}
```

```javascript
if (index < array.length) {
  visit(array[index]);
}
```

最后一个有效下标是长度减一。重点标记用于解释，不代表代码会自动执行。

:::mbb:end
````

前台桌面并排、窄屏上下显示。行级差异与作者重点分开标记，复制按钮只复制对应原代码；浏览器不允许自动复制时提供只读源码框供手动复制。较长代码先显示有限行的标注，后续可展开；超出差异计算预算时明确标为按相同行位置估计，不将它宣称为精确最小差异。每篇的标注数量也有共享上限，未标注的原代码仍可读、可复制。

## 切换同一题目的不同代码版本

实际验收方法和范围见[验证范围](VALIDATION.md)。在区块插入器选择“多语言代码页签”，分别添加各版本的语言、可选标题与原代码。可以使用不同程序语言，也可以用同语言的两个实现；标题为空时使用语言名称或“代码”。这与前面的左右代码差异对照是不同用途，页签不会判断算法等价，也不会执行代码。

作者可添加、删除、调整顺序并明确选择默认版本。删除默认版本前须先选择另一个默认；只剩一版时删除整个代码组。组和各版本的稳定 ID 要在文章内唯一，改标题或移动顺序时保留 ID。使用“复制代码组”会生成全部新 ID；核心编辑器直接重复组可能仍保留原 ID，保存时会明确拒绝冲突。

````text
:::mbb:v1 code-tabs {"id":"sum-versions","defaultTab":"sum-python","tabs":[{"id":"sum-python","title":"Python","terminalNewline":true},{"id":"sum-javascript","title":"JavaScript","terminalNewline":true}]}

```python
def total(values):
    return sum(values)
```

```javascript
function total(values) {
  return values.reduce((sum, value) => sum + value, 0);
}
```

:::mbb:end
````

JSON 与围栏的顺序一一对应；不要在组内增加解释段落，解释放在代码组前后。`terminalNewline` 表示该版原代码是否带末尾 LF：为 `false` 时，围栏前的最后一个 LF 仅作分隔，不属于原代码。生成器会选择足够长的围栏，代码中的围栏和教学标记仍是字面代码。保留原空白、缩进、CRLF 与混合换行；编辑框显示换行可能经过浏览器处理，真正修改之后仍须检查普通差异与预览。

最多八个版本，每版 64 KiB、全组 128 KiB，完整文档三通道仍各限 256 KiB。标题最多 200 个单行字符；语言使用最多 64 位 ASCII 字母、数字、下划线或加减号，未知语言只显示原代码，不下载任意高亮脚本。

读者可以点击顶部语言页签、使用左右箭头及 Home／End 切换。可选的实现说明显示在当前代码面板的标题中，顶部只显示语言；右上角提供复制按钮。每版的 `#稳定ID` 深链接会揭示所属折叠与阶段，浏览器返回恢复视图。复制只取该版原代码；操作系统或手动选择文本框可能规范化换行。前台不提供代码下载或额外的显示全部按钮。网页切换全文阅读时仍保留当前语言页签；无脚本与打印显示全部版本。读者选择不会回写文章。长代码溢出时有横向滚动提示，也可聚焦代码区域后使用键盘查看。

## 插入可交互教学组件

先由管理员安装并启用经过审核的独立教学扩展。作者在区块插入器选择“教学组件”，从已登记的兼容组件中选择类型，填写受校验参数，并在其内部写好静态替代内容。参数输入先保留为候选，点击“应用参数”才更新区块配置；点击“撤销参数输入”恢复已应用值。未应用或无效的输入会暂停原生保存与配对导出，切换选区再回来仍保留候选，避免把旧参数误当成新输入保存。服务端还会在保存时按扩展 schema 校验；应用按钮不是绕过校验的许可。主插件不提供课程题目，也不在正文中保存算法脚本、外部嵌入地址或运行轨迹。

下面是独立数组样例的格式示例。扩展必须登记对应类型与版本，新增或修改参数才能保存；没有扩展时，已有合法配置与静态解释仍保留。

```markdown
:::mbb:v1 component {"id":"sort-demo","component":"insertion-sort","componentVersion":"0.1.0","params":{"values":[5,2,4,1,3],"order":"asc"}}

### 不运行组件也能阅读的解释

原数组是 5、2、4、1、3，升序结果是 1、2、3、4、5。每轮将当前元素插入已排序前缀。

:::mbb:end
```

`params` 必须是纯 JSON 对象；对象与数组不能混用。参数总量最多 16 KiB、1,024 个节点、八层深度，扩展自己的 schema 可进一步限制。数值采用 JavaScript 的有限双精度数语义；需要精确保存超大整数的组件应使用经 schema 校验的字符串。类型、兼容版本和稳定实例标识与参数一起保存；读者临时输入和运行结果不会改变这些作者配置。

编辑器默认显示静态替代；选中组件后，在区块设置的“教学配置”面板明确点击启动交互预览，运行区域与编辑器隔离。前台也按需加载登记资源。关闭、停止或重置后可以重新开始；组件缺失、版本不兼容、加载失败或摘要不符时显示原因，静态解释仍可阅读。不要通过修改正文参数来指定资源 URL 或任意代码。

## 阅读演示与受控实验

数组样例提供播放、暂停、单步、后退、重置、速度与典型输入切换，以及数组状态与代码位置联动。回放的后退通过保留的有限轨迹实现；播放进度只是本次浏览器中的阅读状态。

预制轨迹回放与真实执行分别标明。受控实验只运行扩展中已审核的固定实现，读者修改限定输入和排序方向，不能粘贴代码执行。数组样例实际执行语言为 JavaScript；运行后展示结果、参照结果、比较与移动次数，以及运行耗时。此耗时包含 Worker 初始化与消息传输，不含动画回放；操作计数不代替复杂度证明。

运行、停止、重置、超预算中止与执行失败具有不同状态。超预算表示此演示达到自身资源上限，不表示平台判题超时。详细输入、输出与轨迹上限由扩展说明；浏览器 Worker 并不构成通用安全沙箱。页面同时活动的运行数有限，达到上限时先停止或关闭另一个实例，再显式重试。

## 保存与兼容

编辑后仍按现有流程查看差异、预览并保存；直接可视化保存也经过服务器反转和配对校验。文章 ID、作者、状态权限、固定链接、评论、私人笔记、来源绑定和修订规则保持。文件来源文章仍同时检查 WordPress 与绑定真实文件的版本，不新增第二份可写正文。原文、规范原文、区块序列化各自最多 256 KiB，属性转义的增长也计算在内。

主插件提供通用教学结构和基本展示，特定课程、算法及执行资源由独立扩展提供。主题可通过 `window.MarkBridgeTeaching.revealTarget(target)` 同步展开目标，监听 document 的 `mbb:teaching-change` 更新可见目录；history 自动定位可先检查 `hasCurrentHistoryView()`，避免覆盖用户保存的收起视图。只对展示控件使用 `data-mbb-generated`，不要给隐藏的作者正文加该标记；目录及段落身份应排除临时输出，继续索引隐藏正文。

2.0.1 增加阶段导航吸附：到达视口顶部后固定，离开所属阶段组时随正文移出；手机上仍保留阶段选择与前后导航，英文模式按钮可自然换行，打印和无 JavaScript 时按完整静态正文阅读。折叠未指定展开状态时关闭，作者明确配置的 `open:true` 仍展开；全文模式、深链接和读者操作可以临时展开，不改写作者配置。

主题可在固定或吸附顶栏上添加 `data-mbb-teaching-sticky-obstruction`，插件会与 WordPress 管理栏一起测量当前顶部遮挡。也可在文章容器设置 `--mbb-teaching-sticky-offset`（CSS 长度，表示顶部总留白）；实际偏移取此值与测量值的较大者。`--mbb-teaching-sticky-background` 控制导航栏的不透明背景。插件按导航栏实际高度为组内锚点留白；主题若覆盖 `scroll-margin-top`，应保留 `--mbb-teaching-effective-offset` 和 `--mbb-teaching-controls-height` 的空间。导航栏祖先应避免 `overflow:auto/hidden/scroll`，可用 `overflow:clip` 限制横向溢出而不创建新的滚动容器。
