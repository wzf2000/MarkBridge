# 公式结构读法与探索

阅读文章时点击公式，或将焦点移到公式后按 Enter，打开公式阅读器。展开“结构读法与逐项探索”，可选择中文结构读法或原始英文语义。中文目前覆盖常见算术、分数、上下标、根式与有限矩阵结构；只有数字指数且英文语义明确为平方、立方或幂时使用“次方”，其余上标按结构描述；组合数等未覆盖的表达式会明确显示英文语义，不将 TeX 源码冒充自然语言。

选择“使用键盘探索”后，↓ 进入子项，←／→ 切换相邻项，↑ 返回上层，Home 回到完整公式。当前子项会在公式中描边，并在下方显示读法；也可以直接使用“上层”“前一项”“后一项”“进入子项”按钮。首次 Esc 退出探索并回到按钮，再按 Esc 关闭阅读器、返回文章中的原公式。语言与选择仅属于当前阅读会话，不写回文章、来源或修订。

## 读法与可访问性边界

结构来自实际 MathJax CHTML 中保存的语义节点。中文是本插件对有限节点类型的结构映射，不是完整的中文语音引擎；无法完整描述时保留原始英文读法。结构树无法安全建立时，阅读器仍保留公式、TeX 和可用的完整英文语义，只停用逐项探索。英文标签与受限预览、离线 HTML 的语义保持原有传递方式。

界面提供键盘、可见定位和 live region 文本；不自动播放声音。系统朗读效果取决于所用浏览器与辅助技术。浏览器自动验收不等于真实屏幕阅读器、盲文终端或实体手机认证。

探索最多读取 2048 个语义节点、64 层关系、单节点 16384 字符读法及合计 512 KiB 英文语义；中文映射另有限定访问和结果长度。超限、重复标识或关系不一致会关闭结构探索，不阻止正文继续阅读。

## 为什么不是直接设置中文 locale

当前锁定的 MathJax 4.1.3 包没有中文 SRE 语言规则。本功能保留它生成的英文语义，再提供范围明确的中文结构读法。MathJax 官方的探索与语义配置见[表达式探索](https://docs.mathjax.org/en/latest/upgrading/whats-new-4.0/explorer.html)及[无障碍选项](https://docs.mathjax.org/en/v4.1/options/accessibility.html)。本插件的中文覆盖以本页所述范围为准。
