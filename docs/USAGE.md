# 内容编辑指南

第一次上传文件请按[入门指南](GETTING-STARTED.md)操作；本文说明如何继续编辑已有文章，以及公式、任务列表和脚注的用法。遇到导入或保存问题请查[常见问题](TROUBLESHOOTING.md)，版本变化见[更新记录](../CHANGELOG.md)。

## 找到并修改已有文章

在 **文章 → 所有文章** 中找到文章并点击 **编辑**。也可以进入 **工具 → Markdown 编辑桥**，找到文章，点击 **Markdown 编辑**。编辑桥列表不显示回收站文章。

在区块编辑器中，直接修改正文并保存即可。要修改 Markdown 或重新导入文件，点击底部 **Markdown 编辑 / 上传**；在“Markdown 与区块编辑”窗口修改原文，或在 **上传 Markdown 文件** 中选择新版文件。核对 **标题** 和 **保存为**，点击 **查看差异与预览**，确认后点击对应的 **确认保存草稿／确认提交审核／确认公开发布／确认私密发布**。成功后会回到文章的区块编辑器。

重新上传会替换窗口中的候选正文，保存前请检查差异。不要通过“上传新文档”重建同一篇文章；稳定文档 ID 用于保持文档身份，已有文章不需要更换 ID。已知旧版本文件会被拒绝，避免覆盖新的编辑结果。

## 草稿、审核和发布

首次导入建议保存草稿，再在文章设置中选择 **特色图片**。有发布权限时可公开或私密发布；没有发布权限时可保存草稿或提交审核。公开／私密发布的新文章需要媒体库中的有效特色图片，正文图片不能代替封面。发布流程见[入门指南](GETTING-STARTED.md#6-添加封面然后发布)。

更换封面后，在文章编辑器保存；在编辑器内打开的 Markdown 窗口也会读取当前选择的特色图片。仅在工具页打开窗口不会提供封面选择器。

## 在可视化编辑器保存

普通 Markdown 托管文章可以直接修改区块，然后使用 WordPress 原生“保存草稿／更新／发布”。服务器把区块转换回 Markdown，验证可安全往返后，将两份正文和本次原生字段修改一起保存。底部“查看差异与预览”作为可选检查入口保留，不再是保存的必经步骤。

遇到无法转换的区块或样式、权限或发布条件不满足、版本冲突时，保存会显示错误并保留当前编辑内容；请先复制重要修改，再处理错误或核对服务器最新版，不要直接刷新丢弃草稿。后台自动保存仍关闭，需手动保存。

绑定服务器 Markdown 源文件的文章仍须预览差异并明确确认写回；未配置受信写回目标时只读。普通非托管文章的原生流程不受影响。

## 行内公式

区块编辑器默认显示行内公式的排版结果。点击公式，或聚焦后按 Enter / 空格，可打开 TeX 源码编辑框和下方的小型预览；选择“应用公式”更新当前公式，取消或 Esc 保留原值。应用公式只更新编辑内容，随后使用文章保存按钮保存；文件来源文章仍需预览并确认写回。

公式排版失败时保留源码。预览节点不写入正文；编辑浮层打开期间公式发生变化时，需要重新选择，避免覆盖新的内容。

## 新建公式（1.2.0）

在 MarkBridge 托管文章的富文本工具栏“更多”中选择“数学（MathJax）”，可以新建公式，或把选中的纯文本作为 TeX 初值。输入不带外层美元符的单行 TeX，等待预览成功后选择“应用公式”；取消不会修改正文。含其他格式或对象的选区不能直接替换，以免丢失格式。

在正文中逐字键入 `$a = b$`，闭合美元符后可自动变成行内公式；一次撤销恢复完整的字面文字。自动识别只处理本次短文本输入，不扫描旧内容，不处理粘贴、输入法组合过程、代码或带其他格式的范围。金额、转义美元符和未闭合表达式保持文字；相邻公式请用空格或文字分隔，或合并为一个 TeX 公式；紧接已有公式的第二段 `$…$` 保持字面文字，避免中间 `$$` 与行间分隔符歧义。有歧义或较长的公式请使用工具栏。普通文字中的美元符仍会在 Markdown 中转义，不能通过取消转义来强制识别。

空段落仅键入 `$$` 后按 Enter，可以创建“行间公式”区块并进入 TeX 输入框；也可从区块插入器选择“行间公式”。选中时编辑源码，离开后显示排版结果。应用或插入公式仍需保存文章，文件来源仍需差异预览和明确确认。

## WordPress 原生数学兼容（1.2.0）

核心的“数学”与插件的“数学（MathJax）”是两种存储格式。插件保留核心格式注册和已有内容，不会自动迁移文章；托管文章的新建行间入口使用插件的“行间公式”，普通非托管文章保持原生入口。

选中已有原生行内数学后，公式旁显示“转换为行内公式（MathJax）”；选中原生数学区块后，区块上方显示“转换为行间公式（MathJax）”。直接点击即可发起核对，原工具栏入口仍保留。只有可恢复的 TeX、可核对的 MathML 且没有会丢失的额外属性时才允许转换；缺少源码、样式不能保留、排版失败或验证期间内容变化都会拒绝，保留原对象。转换成功后才进入既有双格式保存链，不会放宽对任意 MathML 或 HTML 的保存限制。

## 正文任务列表

Markdown 使用 `- [ ]` 和 `- [x]`（也接受 `[X]`）。区块插入器选择“任务列表”，在后台勾选完成状态并编辑任务内容；支持普通项混排、有序列表、嵌套、后续段落、引用、代码与公式。前台复选框只读，修改继续经过现有差异、预览、权限和配对保存流程。

删除最后一个任务后，如果剩余内容可表示为普通列表，选中列表容器，在区块工具栏中选择“转换为普通列表”再导出。复杂的多段落普通列表继续保留原区块。两个独立的同类列表之间需要正文段落分隔；紧邻列表在 Markdown 中会合并，无法保留原区块结构时会拒绝导出。

历史复杂列表中作为普通段落保存的 `[x]` 仍可精确恢复旧配对，但前台显示字面标记；显式重新导入原 Markdown 后才使用新的任务状态区块。转义标记和代码内容不作为任务，不自动迁移既有文章。

## 脚注

使用命名引用与定义；脚注名称支持 1–64 个字母（含中文）、数字、下划线或连字符，区分大小写：

```markdown
正文中的说明[^note]，再次引用[^note]。

[^note]: 第一段说明。

    第二段说明，也可以包含已有支持的列表、代码或公式。
```

后台可在正文富文本工具栏的“更多”中选择“插入或修改脚注引用”；在文末插入一个“脚注定义”区块，为每个脚注填写同名名称并编辑内容。引用改名后也须修改对应定义及其他引用，否则配对校验会拒绝保存。可以继续直接在 Markdown 编辑桥中编辑，再检查差异与预览。

前台按首次引用顺序编号，重复引用分别提供返回链接；同页多篇文章互不串跳。保存时保留定义顺序，不把阅读编号写回 Markdown。删除引用时同时删除不再使用的定义。

缺失、重复、未使用的定义、脚注定义中的脚注引用、链接或图片文字中的引用会明确拒绝。匿名 `^[说明]`、原生 WordPress 脚注区块或第三方脚注格式不自动转换。代码与转义文字保持字面；历史普通文字中的未定义标记仅允许精确恢复旧配对，不自动迁移。

## 检查差异和处理版本冲突

Markdown 窗口的 **查看差异与预览** 会比较服务器已保存正文和当前候选。检查新增、删除或修改的段落后再保存。修改候选会使旧预览失效，需要重新预览。

如果保存时出现“版本冲突：核对服务器与当前候选”，先使用 **下载当前候选 .md** 保留自己的修改，再点击 **重新读取服务器最新版**，比较双方标题、状态与正文。点击 **保留我的修改，基于最新版继续**，核对并编辑候选，重新预览后明确保存。不会自动合并，也不会在检测到冲突后覆盖服务器版本。

## 恢复历史版本

先保存当前未保存的修改，再在 **工具 → Markdown 编辑桥** 的文章列表或编辑器底部点击 **历史版本 / 恢复**。选择修订，点击 **查看恢复差异与预览**，核对后点击 **确认恢复两种格式**。恢复所选版本的标题、Markdown 和区块，保留文章 ID、作者和当前可见性；当前已保存版本会留在历史记录中。文件来源文章不能从此入口直接恢复，请通过既有源文件同步流程处理。

## 删除、还原和文件来源文章

在 **文章 → 所有文章** 中将文章移至回收站；需要恢复时进入 **回收站 → 还原**。移入回收站会保留两种正文，确认不再需要后可永久删除。

电脑上上传的 `.md` 文件与文章之间没有持续同步关系。只有由管理员另行配置并绑定服务器可信文件的文章，才属于“文件来源文章”。这类文章可能显示 **Markdown 原文 / 预览**；可写回时必须先预览并明确确认写回，未配置目标时只读。服务器文件不可读时，窗口显示 WordPress 已保存副本并保持只读，该副本可能不是文件最新版。请联系管理员或使用对应的同步流程；删除 WordPress 文章也不会删除外部源文件。
