# 常见问题

本文适用于 MarkBridge **3.0.0-rc.2**。第一次导入请先看[快速开始](GETTING-STARTED.md)。遇到错误时，先复制未保存的正文；不要立即刷新或关闭窗口。MarkBridge 的校验错误会阻止保存，处理后需要重新预览或再次保存。

## 入口与导入

### 找不到“导入 Markdown”

这个入口位于 **文章 → 新建文章** 的区块编辑器顶部。已有文章请使用底部 **Markdown 编辑 / 上传**；也可以从 **工具 → Markdown 编辑桥** 打开。

若工具菜单也没有入口，请让管理员确认插件已启用、所选转换后端诊断通过，以及当前账号有编辑权限。安装和服务器配置见[安装与升级](INSTALL.md)，普通作者不需要自行构建插件。

### 提示“当前新文章已有未保存内容”

新文章的标题或正文已有输入时，顶部导入入口会阻止导入。先保存已有内容，再另开一篇空白新文章；只在确实不需要这些内容时清空后导入。

### 选择文件后没有生成文章

“文件已读取，尚未保存”是正常提示。选择文件只是把正文填入窗口。还需要填写 **标题**、**稳定文档 ID**，选择 **保存为 → 草稿**，点击 **查看差异与预览 → 确认保存草稿**。成功后会自动跳到文章编辑器。

文件名和正文一级标题不会自动填入 WordPress 标题。版本化 Front Matter 默认也不应用；需要使用提案标题时，在元数据面板明确选择，再预览与确认。若显示乱码，请把文件另存为 UTF-8 后重试。

### 文档 ID 无效或已存在

ID 需为 3–64 个字符，以英文字母开头，其他字符仅限英文字母、数字、下划线和连字符。例如 `first-markdown-post`，不要使用中文、空格或以数字开头。

如果提示“文档ID已存在”，先检查是否已保存过这篇文章。需要修改原文章时，从 **文章 → 所有文章** 或编辑桥列表打开它；需要新建另一篇时，使用不同 ID。不要通过更换 ID 来覆盖或替代原文章。

### 文件过大或请求过大

普通 Markdown 文件选择上限是 **1,500,000 字节**，不是 1.5 MiB；PHP 每种配对正文仍最多 256 KiB。图片 ZIP 的独立上限为 8 MiB，具体图片、展开量和服务器条件见[资源导入](USAGE.md#导入带本地图片的文稿)。服务器也会检查正文、区块和整个请求的大小；接近文件上限时，请求仍可能因额外数据超限。

将长稿分成内容独立的文章，或精简后再导入。每篇新文章使用独立文档 ID。不要把图片编码为大段文本嵌入文件；通过媒体库上传图片，再在正文使用可访问的图片 URL。

## 保存与发布

### 预览后“确认保存”按钮仍不可用

确认预览已经显示“校验通过”。如果窗口有错误，先处理错误；如果预览后改过标题、正文或状态，请重新点击 **查看差异与预览**。

文件来源文章只读、未解决的版本冲突或仍在处理中的请求也会停用保存。普通区块编辑完成后，可直接使用文章编辑器的保存／更新按钮。

### 发布要求特色图片，或者没有发布选项

新文章公开／私密发布需要有效的特色图片。先将导入内容保存为草稿，进入区块编辑器，在右侧文章设置中选择 **特色图片**，再发布。Markdown 正文里的图片不能代替封面；工具页的导入窗口没有封面选择器。

没有发布权限时，**保存为** 只提供 **草稿** 和 **待审核**。保存草稿或提交审核，请有发布权限的人继续处理。

### 导入后图片不显示

普通 `.md` 导入不会上传附件或将本地相对路径改成媒体库 URL。可以先通过 WordPress 媒体库上传图片并替换 Markdown 地址；也可以按[图片 ZIP 导入](USAGE.md#导入带本地图片的文稿)打包文稿和受支持位图，核对图片、接受媒体公开提示，再预览与确认保存。ZIP 预览中的临时地址须经确认保存才会成为最终媒体 URL。已有网页图片还需确认 URL 可访问，且不会因权限或失效地址而无法加载。

### 保存提示不支持的区块、样式或 HTML

错误现在会在有证据时标出 Markdown 行、区块路径或属性，并给出处理建议。行号表示该原文区块的开始位置；序列化位置不是 Markdown 行号。没有定位信息时不要据此推断出错行。

托管编辑器底部的 **转换支持与当前内容** 会提示不支持的区块；展开后点击 **检查当前区块转换** 可提前检查当前内容。此检查不保存，服务器仍在保存时重新验证。

MarkBridge 只接受能安全转换并往返的内容，不能保证任意第三方区块或 HTML 都可保存。先保留自己的修改，再把刚加入的复杂区块或样式改为支持的段落、列表、表格等，重试保存。

公式、任务列表和脚注的具体限制见[编辑与发布](USAGE.md)。不要为了通过校验直接删除不理解的内容，必要时把错误信息和复现步骤交给管理员。

## 冲突、旧文件与源文件

### 出现版本冲突

服务器文章或绑定源文件在你编辑期间发生了变化。窗口会显示 **版本冲突：核对服务器与当前候选**，并停用保存。

1. 点击 **下载当前候选 .md** 保留修改；若当前候选尚不能转换为 Markdown，请复制重要文字并保留当前编辑页。
2. 点击 **重新读取服务器最新版**，比较服务器与候选的标题、状态和正文。
3. 点击 **保留我的修改，基于最新版继续** 后，核对并手动合并需要保留的内容。
4. 重新点击 **查看差异与预览**，确认后保存。

“基于最新版继续”不会自动合并正文，也不会自动保存。直接刷新可能丢失未保存内容。

### 上传文件提示“已知旧版本”

这份文件曾是该文章的历史版本，而服务器已有更新。不要反复上传同一个旧文件来覆盖当前内容。先打开原文章，核对最新版，再通过 Markdown 编辑合并需要的内容；要恢复旧稿，使用 **历史版本 / 恢复** 并检查预览。

### “正文由源文件同步”或 Markdown 只能查看

这通常是管理员另行绑定的服务器文件来源文章，与电脑上传 `.md` 新建文章不同。未配置受信写回目标时，后台只读；绑定文件无法读取时，会显示 WordPress 已保存副本，该副本可能不是最新版。

请联系负责该文件来源的管理员或通过既有同步工具更新。普通上传不会创建这种绑定，也不会修改你电脑上的原文件。

## 公式与页面显示

### 公式显示源码、脚注无法保存

公式排版失败时会保留 TeX 源码，请核对语法并重新预览。新建行内公式使用工具栏 **数学（MathJax）**，TeX 输入框不需要外层美元符。

脚注引用和定义必须同名；缺失、重复、未使用的定义或定义内再次引用脚注会拒绝保存。命名、任务列表和原生数学转换边界见[编辑与发布](USAGE.md)。

### 已保存但页面样式与预览不同

编辑桥预览用于检查转换后的正文；实际页面使用你的 WordPress 主题、页面布局和其他插件样式。保存后使用 WordPress 的预览或 **查看文章** 检查最终效果。若遇到登录失效或“无法验证此保存请求”，先保留未保存内容，重新登录并打开编辑器后重试。

## 管理员配置

### 启用后提示缺少转换运行环境

请管理员进入 **设置 → MarkBridge** 查看当前后端。新安装默认 PHP，需 WordPress 7.1.x、PHP 8.2+、DOM／mbstring；包内依赖已有，不需安装 Node。已有 Node 配置则继续使用其私有目录，须按[服务器配置](RUNTIME.md)检查匹配版本，或在 **转换方案** 选择 PHP 并验证应用。普通作者上传 Markdown 不能修复服务器配置。

### 升级后提示运行环境失配或沙箱失败

WordPress 核心、转换内核或运行依赖与目录清单失配时会阻止写入。管理员应从同版本源码在新目录准备环境，完成沙箱诊断后切换；不要覆盖旧目录，也不要绕过隔离执行。详细要求与协调回退见[服务器配置](RUNTIME.md)。

### 公式差异预览字体异常

如果额外设置了内容安全策略（CSP），管理员检查 `font-src` 是否允许 `data:`；差异预览需要嵌入受信的本地数学字体。不要为此放宽 iframe 的脚本或同源权限。

### 如何反馈仍未解决的问题

先保留未保存内容，再提供插件与 WordPress 版本、操作入口、最短复现步骤、准确错误提示和去除私人内容的示例。不要发送密码、cookie、nonce 或未脱敏的私人文章。管理员可查看设置页诊断；配置细节仅对有 `manage_options` 权限的管理员显示。

## 为什么选择 Node 失败或不能切换后端？

Node 不是后台自动安装的组件。管理员需先准备匹配版本的私有运行环境，确保 PHP 用户能读取并通过隔离转换；失败候选不会替换当前配置，失败详情与当前引擎诊断分开展示。选 PHP 不需要填写 Node 路径，保留原路径以便切回。

如果选择表单被禁用，请检查 `MARKBRIDGE_CONVERTER_BACKEND` 是否由服务器定义；后台不能覆盖它。`MARKBRIDGE_RUNTIME` 只将 Node 目录设为只读，管理员仍可选 PHP。新配置损坏时明确拒绝转换，可重新验证并保存合法方案，不会自动沿用旧配置猜测后端。详细优先级见[服务器配置](RUNTIME.md#后端选择与诊断)。

## 公式或教学组件加载失败时如何定位

先保留静态正文。公式阅读窗口会保留 TeX 源码，加载失败后可选择“重新排版公式”；
教学组件可重新启动，运行中的算法不会被自动重新执行。HTTP 错误、内容类型不符、
资源摘要不匹配与超预算分别处理，不能将摘要不匹配当作网络缓慢反复下载。

管理员遇到错误时可展开“技术详情”，明确点击“复制诊断摘要”。浏览器拒绝复制时，
会选中只读摘要供手动复制。摘要只包含插件／组件版本、错误码、阶段与粗粒度耗时；
不包含正文、TeX、参数、账号、来源路径、资源 URL、Cookie 或 nonce。
普通读者不显示该技术面板。成功重试、开始新一次执行或关闭组件会清除旧错误，
正常就绪和关闭不保留状态文案。

诊断仅存在当前页面内存，不会默认上传或长期记录。提交问题时可附该摘要和操作步骤；
截图、开发者工具日志和手工粘贴的正文可能另外含有私人信息，复制摘要并不会替它们脱敏。
