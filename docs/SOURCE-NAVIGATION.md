# 长文编辑与预览定位

适用于MarkBridge 3.0.0 正式稳定版。入口仍是“Markdown 编辑／上传”，保存仍须先检查差异和预览，再确认。

## 阅读和修改长文

展开“查找、替换与定位”，填写字面文本后查找上一处／下一处，或替换选中匹配／全部匹配。
不执行正则表达式。匹配超过 10000 时需缩小范围；替换后的源码仍须符合 256 KiB 上限。
“跳转行号”使用当前编辑框的实际行号。撤销、重做和中文输入事务保留在当前窗口（最多 80 个事务、合计 8 MiB），关闭窗口
不构成持久修订；保存后的恢复仍使用配对历史版本。

未直接键入源码时，替换只修改选中的原文范围，其他 CRLF、缩进及尾随空白保留。新增换行
沿用源稿第一个换行样式。直接在 textarea 键入时，浏览器会规范化该框的换行，界面会提醒；
在当前撤销历史仍保留该事务时，可以回到规范化前的原始来源。查找和视图切换不会改写来源。

先生成当前预览。在预览栏启用“定位源码”，再点击段落、公式或代码，或用 Tab 和 Enter
选择目标；普通链接和折叠控制不被当作定位点击。预览外部链接不跳出此隔离文档。
从源码选区使用“在预览中定位选区”可反向查找；所属折叠会在预览内展开。
列表、引用和部分嵌套结构只定位可证明的完整容器，并明确提示；不通过显示文字猜测重复内容。
Front Matter 没有可见正文，不提供虚假的预览目标。ZIP 资源投影改写了源码时暂不提供映射。

桌面可开启“源码与预览并排”；窄屏继续使用两个视图切换。同步滚动默认关闭，可明确启用，
以已验证的内容锚点联动。滚动不改变源码选区，也不将两侧总高度强行按比例对应。
源码或目标文章变化后，旧映射立即失效，须重新预览；旧结果不覆盖新输入。

“插入教学结构”提供折叠、阶段、代码页签和已启用图示扩展的样例。插入生成新稳定标识，
仍是未保存候选。先改写解释和静态替代，再预览和确认。读者播放、选择和临时结果不写入正文。

## 派生接口与隔离边界

`sourceNavigation(rawSource, parsedBlocks)` 与 PHP `mbb_source_navigation()` 只计算位置。
预览响应 `navigation` 为 schema 1、UTF-16 半开偏移，含原始 UTF-8 `sourceSha256`，最多
2048 个范围及 2048 个未映射说明。每项包含 `id`、`blockPath`、`kind`、`start/end`、
`startLine/endLine`、`precision: exact|coarse`。语义路径忽略空白自由区块；范围 ID 仅属于本次快照。

`exact` 表示完整语法对象的边界准确，不承诺每个渲染字符都有对应光标位置。未知结构保守
拒绝映射，不能使原有转换或保存失败。保留导航属性在作者 HTML 中先移除，再只向临时
预览注入；不写入区块属性、正文、来源文件或修订。

作者桥为固定本地脚本，以精确 CSP SHA-256 放行。预览 iframe 为 opaque origin，仅有
`allow-scripts`，没有 `allow-same-origin`；连接、Worker、子 iframe、对象、表单及任意正文
脚本关闭。宿主验证 frame 身份、null origin、随机会话、当前候选版本、源稿摘要、闭集消息
字段及范围白名单。桥只能传递范围 ID，不能请求保存、运行算法、读取凭据或发送正文。
普通图片继续可展示；字体为本地排版后的内嵌数据。导航不可用时退回静态预览，不放宽权限。
