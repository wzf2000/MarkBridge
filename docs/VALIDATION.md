## 边界与限制

- 最小转换适配器验证策略和构建；合成 REST 验证界面交互，都不能替代完整 WordPress 保存与权限验证。
- 本轮实际写入限定管理员和合成草稿。权限保护沿用原有规则，未重新执行全部角色及来源文件写回生产矩阵。
- 未覆盖 Safari、Firefox、所有主题／插件组合或完整数学无障碍支持。实际安装可能仍有主题、媒体探测或无头浏览器 GPU 警告，不声称整个站点控制台无警告。
- 任务列表前台只读；旧复杂列表的字面任务标记不自动迁移。
- 脚注仅支持具名引用；匿名、嵌套引用、原生 WordPress 或第三方脚注格式不自动转换。
- 回退须协调插件与转换环境，并保留升级后的正文和修订；旧版不能继续编辑新增区块。本轮未执行整库恢复演练。
