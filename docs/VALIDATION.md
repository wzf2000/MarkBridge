# 0.7.0-rc.3 验证范围

本页记录统一发行候选的实际检查；最终 ZIP 以随包清单中的源码提交和外部 SHA-256 定位。旧版本证据保留在 [历史记录](archive/VALIDATION-0.7.0-RC.md)，不替代本候选检查。

## 环境与已验证行为

Linux、WordPress 7.1、PHP 8.2.32、Node.js 24.21.0；使用两套独立合成数据库和最小测试主题，不导入真实站点数据库。

- 源码格式、PHP 语法、构建、版本/资源完整性与私有部署信息扫描通过。
- 内核 7 组 Markdown 精确往返、3 组内容策略拒绝、Unicode/代码边界通过。
- 首次未配置、数据库配置、常量优先及无效常量不回退通过。实际管理员诊断、非法 nonce 拒绝、普通作者禁止访问和手机页面检查通过。
- 缺失目录、公共目录、读取权限不足、内核/启动快照失配及依赖缺失导致转换失败均被检测；失配阻止配对写入。
- 新目录运行环境构建成功；合成转换失败时清理暂存目录，不替换旧环境。
- 不同系统用户共享无数据转换锁：持锁时并发转换被拒绝，释放后另一个用户可用只读文件描述符取得独占锁；无需扩大私有源文件权限。
- 图片数据包后台实际上传、启用、删除、正文/评论显示与切回 Unicode 通过；浏览器图片请求失败可读回退，未知码与代码区域保留。安装、选择、删除、失败保留旧选择通过。路径穿越、链接、额外文件、超大文件、错误校验值、伪装图片和 PHP 混入均拒绝；数据库拒绝更新不会报告切换成功。
- 合成旧版升级前后，文章 ID、双格式正文、修订、来源绑定、评论、私有笔记记录及权限快照一致。实际恢复旧数据库、插件与运行配置后快照相等，旧版保存、回收站恢复及正确/错误源路径校验通过。
- 实际 Gutenberg UI 输入行内公式，整段预览、配对保存、重开和前台公式通过；匿名评论真实表单提交、待审核、管理员审核及 Markdown 展示通过。

浏览器评论路径发现任务标记过滤早于 WordPress 段落恢复的问题；候选已将评论展示过滤移至 `wpautop` 之后，正文过滤顺序不变，不改写已存评论；真实评论针对复验通过。图片包实测还发现核心 `convert_smilies` 会提前消费命名短代码，现仅在正文/评论展示过滤期间保留这类映射，普通 ASCII 笑脸仍沿用核心处理。

## 边界

这是限定环境的候选验收，不是广泛主机/主题矩阵或真实站点整库恢复。图片包未包含未知许可第三方素材，默认 Unicode；后台回写源文件和 R10-04 新建文章导入入口仍未实现。公开推送、版本标签、GitHub Release 和任何生产升级均独立执行，不由自动检查触发。

R07/R10 的原完成标准继续见 [路线](plans/active/ROADMAP.md)。最终发行还需从固定提交干净构建、核验 ZIP 与清单，并对最终包完成短闭环；这些动作由 [发布流程](RELEASING.md) 规定，不能仅凭本页描述替代。
