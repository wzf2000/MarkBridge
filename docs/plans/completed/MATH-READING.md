# 公式阅读工具

状态：实现与隔离验收完成（2026-09-26），尚未发布。基于当前未发布的浏览器回归与长文差异分支继续开发。

## 范围与完成标准

- 前台公式可通过点击或键盘打开阅读弹窗，提供原始 TeX、复制、放大/缩小和恢复默认字号。
- 保留 CHTML 与现有排版；长公式在弹窗内横向滚动，手机页面不溢出。关闭时恢复入口焦点，Esc 可关闭。
- 复制失败时可手动选取源码；排版失败仍保留可读源码。源码使用文本节点，不执行其中标记。
- 不改变公式的保存表示、正文、权限或服务器接口；不持久化阅读中的私有文本。不接管链接内公式的导航，也不在可编辑区域注入阅读控件。
- 使用已有浏览器回归验证桌面、手机、复制成功/失败、键盘、缩放、原文保持及错误恢复。

## 边界

本轮不提供 SVG/CHTML 切换或完整数学探索器。不对无脚本的编辑预览 iframe 注入不可操作控件；预览继续使用相同 CHTML 排版。此处的阅读工具不等同于完整数学无障碍语义支持。
