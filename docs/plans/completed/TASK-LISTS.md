# 正文任务列表

状态：实现和隔离验收完成（2026-09-26），尚未发布或部署。当前能力、限制和证据分别见 [README](../../../README.md)、[架构](../../ARCHITECTURE.md) 与 [验证范围](../../VALIDATION.md)。

## 范围

支持 Markdown 的未完成与已完成任务标记、普通/任务混合项、有序/无序、嵌套、多段落，以及任务内引用、公式与代码。区块具有明确完成状态，后台可以修改；前台保持只读，不提供匿名状态写入。

保留普通列表与已有复杂列表的存储兼容、原始 Markdown 和严格往返检查。代码、转义标记不应误作任务。不放宽 HTML 安全规则、来源绑定或配对保存权限。

## 完成标准（已完成）

1. 确定区块状态和序列化契约，再实现解析、反向转换与后台控件。
2. 检查真实核心脚本下的导入、解析、状态修改、序列化、导出及重新导入，验证无损或明确拒绝。
3. 检查前台只读展示、过滤后的标记和后台状态控件；普通列表、代码与已有浏览器用例不回归。
4. 运行相关保存、修订、权限和冲突回归，更新当前文档并归档。

## 边界

只读前台与后台状态编辑不等于新增前台写入 API。通过 Markdown 编辑桥的修改继续先预览再确认，并沿用既有配对修订和来源规则。公开推送、发行与生产切换另行处理。
