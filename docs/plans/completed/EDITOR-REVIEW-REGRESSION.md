# 浏览器回归与长文差异、冲突处理

状态：实现与隔离验收完成（2026-09-26），尚未提交发布。基线：1.0.9；本轮未推送、发布或部署。

## 范围

- 公共 CI 使用合成数据和本地构建资源运行真实 Chromium，覆盖 CHTML 样式、行内基线、长代码行号及桌面/手机布局；不依赖生产站、真实文章或登录材料。
- 长文差异显示多个修改片段、上下文及旧/新行号，限制极端输入的计算和 DOM 开销。
- 并发冲突时保留用户候选，允许下载 Markdown；读取最新版本并比较，经明确确认才采用新基线，再次预览后才能保存。
- 继续沿用服务端权限、来源目标、双端指纹与配对保存规则；不自动合并、不强制覆盖、不将私有候选写入浏览器持久存储。

## 执行顺序与完成条件

1. 核对实际 1.0.9 代码和当前文档，修正已完成任务的陈旧入口。
2. 分别实现差异/冲突界面和浏览器测试，两者在合成 REST 响应场景中集成。
3. 验证分散修改、增删、相同文本、长输入、恶意 HTML 文本、普通/来源文章冲突、读取失败、过期异步结果和预览失败；源读取失败不能推进基线。
4. 检查桌面与手机交互、候选下载及再次确认；显示测试必须能识别旧缺陷，不能只数转换成功标记。
5. 运行相关既有回归与格式/构建检查，记录实际通过范围，更新架构、操作和验证文档后归档本计划。

## 验收边界

浏览器合成 REST 测试证明前端状态机与实际 DOM 行为，不等于真实 WordPress 权限、数据库事务或生产端到端验收。现有 PHP/转换/编辑器检查继续保留；本轮不扩大主机、PHP、WordPress、主题或浏览器支持声明。新功能发布和生产切换另按届时授权处理。

## 实际结果与交付边界

- 20 项 Chromium 检查通过，包含桌面/手机尺寸、CHTML CSSOM/字体、120 行代码实际文字与行号坐标、两万行差异、冲突下载/采用/重新预览、来源读取失败和指纹不匹配、拒绝预览、非执行差异文字及迟到响应。两个故障对照分别删除输出 CSSOM 和恢复旧代码排版，检查能辨认退化。
- 匹配 WordPress 核心脚本的本地转换环境：11 组精确往返、3 组策略拒绝与公式/代码边界检查通过；新建文章保护和源读取回退通过。来源原子写入及 CLI 同步保护回归通过。
- 主审另做 500 组确定性增删/重复行重构与行号检查，全部通过；截图复核发现的手机五位行号挤出已修正并加入检查。
- 全量格式、构建、PHP 语法和发行源码/资源检查通过；本轮未构建新版发行包。
- CI 工作流已加入浏览器步骤及失败附件。GitHub 尚未运行本分支；合成 REST 不代表真实 WordPress 数据库验收，手机 Chromium 不代表 Safari。发行和部署不属于本计划实施完成的结论。
