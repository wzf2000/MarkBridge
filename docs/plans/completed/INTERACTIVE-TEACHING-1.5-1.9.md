## 职责与不变量

- 主插件负责通用格式、区块编辑、PHP／Node 转换、静态预览、配对保存、阅读行为和组件注册契约；不硬编码具体算法。
- 独立教学扩展负责算法实现、运行资源、播放与执行控制、参数校验和预算；课程方向提供题目、推导、样例、参照结果及计数口径。
- 主题及兼容层适配目录、样式与段落评论；基本阅读不能依赖特定主题。本轮只用合成内容，不修改真实课程文章。
- 保留 schema 1、文章身份、来源绑定、权限、版本指纹、修订、评论与私人笔记；不增加第二份可写正文。
- 新教学容器使用命名空间、格式版本和稳定标识；标题与顺序变化不改变标识，重复标识、非法属性及结构明确拒绝。
- 折叠最多三层，支持已有安全正文；每篇最多一个阶段组，阶段不嵌套，内部可含折叠与代码对照。默认全文，文章可选择阶段模式；继续不代表学习完成。
- 代码对照保存两份原字符串、语言、标题和解释；差异仅用于展示，复制原文不带标记，空白和缩进不改写。
- 显示切换保留原 DOM；目录、锚点、脚注与评论定位先显示阶段、展开折叠再定位，history 状态与其他组件共存。
- 原文、规范原文和区块各自仍最多 256 KiB，检查完整序列化及转义增长。

## 扩展与执行

- 主插件保存通用组件外壳：类型、格式和组件版本、稳定实例标识、受校验参数、静态替代。缺失或不兼容时显示原因并保留原配置；新增／修改参数需要兼容实现校验。
- 编辑器默认静态预览；交互预览显式启动并隔离，不放宽无脚本预览，不接受任意脚本或外部嵌入。
- 只运行登记实现，读者仅改限定输入和参数；首个执行器标明 JavaScript，任意代码执行另行评估。
- 输入、执行时间、输出及轨迹分别限额；Worker 不作为完整安全沙箱承诺，不能取得 WordPress 登录材料、私人数据或服务器执行权限。
- 真实执行、回放、预计结果、停止、预算中止及失败区分展示；动画与计算耗时分离，操作计数定义明确。
- 读者输入、进度和输出只为临时状态，不回写文章。大型资源版本化并按需加载。

## 完成标准

1. PHP／Node 导入、反转、编辑与严格配对恢复一致；真实合成 WordPress 保存重开、修订恢复、受信文件同步、权限及并发冲突通过。
2. 嵌套、公式代码、脚注、目录、锚点、浏览器返回及段落评论兼容；普通非托管流程无回归。
3. 桌面／手机 Chromium、键盘、焦点与减少动画通过；全文、打印、无脚本、资源失败仍可阅读核心内容。
4. 组件配置可保存重开；缺失或不兼容时静态替代与原配置保留；预览不能执行正文脚本。
5. 执行覆盖停止、预算中止、重置、迟到消息、资源失败及结果口径，验证隔离边界。
6. 格式、现有回归、依赖与构建清单通过；有效契约和实际验证更新到当前文档后归档计划，不生成重复完成总结。

## 1.8／1.9 收口范围

1.8 加固本轮教学接口，不借稳定性名义添加任意代码执行、服务器学习记录或新正文源。运行容器关闭、正文移除、重新打开或重置时终止计时器、Worker 和监听；旧会话与运行 ID 的迟到消息丢弃。多实例共享有限活动执行数与展示预算；资源 404、摘要不符、初始化失败和超预算均保留静态替代与文章继续阅读，并能显式重试。运行、回放、暂停、停止与故障状态不混用；焦点、键盘和减少动画覆盖桌面与手机。

1.9 固化主插件与独立扩展的 v1 注册合同：组件与协议版本、最低主插件版本、纯数据参数 schema、固定本地资源及摘要、预算声明和明确的兼容拒绝。新增管理员只读组件诊断，作者使用兼容组件的配置入口；不下载或自动执行远端包。独立样例有自己的构建、许可证、文件清单和测试入口，算法实现、Worker 和轨迹均不进入主插件。文档说明停用／缺包／升级后的保配置、静态替代与修复方式；合成验收覆盖注册冲突、非法资源、版本不兼容、停用与重启，不能用 mock 宣称实际 WordPress 或浏览器通过。

最终候选仅供统一审查：完整安装包在新建 WordPress 7.1.3 合成库验证 PHP／Node、保存重开、修订恢复、来源同步、权限与冲突，完整桌面／手机 Chromium 回归不跳过或重试掩盖失败。PHP 8.3／8.4 等未在本地运行的环境按实际边界记录；不把旧 CI 当成本轮 CI。
