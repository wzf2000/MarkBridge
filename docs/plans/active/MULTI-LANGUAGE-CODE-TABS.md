## 产品范围

作者在同一个代码组中维护多个实现，例如 Python、C++、Java、JavaScript；读者像常见算法题解一样选择页签阅读。主插件提供通用内容格式、编辑、保存与展示，不提供具体算法或声称不同实现逻辑等价。各版本代码不自动执行，与教学受控运行组件分开。

- 组与各版本具有稳定标识，保存语言标记、可选显示标题、排序、默认页签和逐字原代码；同语言的不同实现可使用不同标题区分。
- Markdown 使用明确可版本化的容器表示，内部复用代码围栏；区块编辑器可新增、删除、排序、选择默认版本和编辑代码，PHP／Node 双向转换一致。
- 前台提供页签、当前语言高亮和单独复制，切换仅改变展示，保留空白、缩进和完整原代码。手机可以横向滚动页签或使用选择器，不造成整页横向溢出。
- 页面深链接可指定稳定页签／代码组；键盘、焦点和读屏语义完整。无脚本、打印和全文阅读时各版本均可阅读并有清晰语言标题。
- 作者配置与读者当前选择分离，读者切换不写回文章。复用既有权限、双格式、来源、修订与版本冲突保护，不新增正文源。

## 格式和资源边界

优先复用教学容器和普通代码能力，但建立独立代码组语义，不复用文章保存差异或正文前后对照来冒充多版本切换。实现时确定有界版本数量和逐版本／全组容量，完整源码、规范源与区块仍分别最多 256 KiB；不静默截断或改写代码。语言采用安全高亮标记，标题按文本处理，正文不得注入脚本、外部运行地址或编译参数。

## 初步验收

1. PHP／Node 导入、反转和编辑后严格配对一致；包含围栏字符、Unicode、空行、缩进、空代码、长代码与同语言多个版本。
2. 真实区块新增／删除／排序／默认版本修改、保存重开、修订恢复和受信来源同步通过；版本冲突保留候选，普通代码无回归。
3. 桌面／手机切换、高亮、复制当前原代码、键盘／读屏、深链接和焦点通过；无脚本／打印仍显示完整代码。
4. 数量与总容量、无效语言、重复标识、非法默认页签和缺失版本明确拒绝；删除当前默认版本须显式选择新默认，不随机改变。
