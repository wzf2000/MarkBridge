# 在两个站点之间携带图片

附件 ID 只在本地 WordPress 数据库中有意义。将旧站 `id:42` 直接带到新站，可能关联到完全不同的图片。需要迁移单篇文章时，在 MarkBridge 文章列表的导出窗口选择“跨站 Markdown 与图片 ZIP”，准备并查看副本，再确认下载。

跨站副本解除图片旧 ID、将经核验的图片打包为按摘要命名的资源，并保留支持范围内的图注、图片尺寸选项及画廊结构。副本会规范化 Markdown 表达，下载前可检查完整源码。源站已保存的文章、修订、评论、私人笔记和来源文件均不修改。每种正文仍限 256 KiB；媒体仍沿用 32 张、单图 8 MiB 及既有总量上限。

在目标站通过 Markdown 上传或批量新建草稿导入此 ZIP，查看预览并确认媒体提示后保存。插件创建新附件及本地 ID，并建立与新文章的关系；不会根据旧站 ID、文件名或看似相同的 URL 复用目标站已有附件。目标站须支持本跨站格式。媒体导入仍受当前用户上传权限、图片安全处理、票据、版本冲突与来源绑定限制。

## 选择适合的导出方式

| 方式                     | 图片关联与用途                                                |
| ------------------------ | ------------------------------------------------------------- |
| Markdown 单文件          | 保留原始字节和当前本地 ID，适合备份原稿；不作为跨站附件迁移包 |
| Markdown 与图片 ZIP      | 保留既有便携投影语义；携带本地 ID 时继续明确拒绝，不暗中改写  |
| 跨站 Markdown 与图片 ZIP | 明确解除旧 ID，导入时创建新附件关系；适合单篇内容带到另一站点 |
| 离线 HTML                | 图片、字体与公式内嵌用于阅读，不重建可编辑文章或媒体库        |

跨站 ZIP 要求每张图片都是当前文章相关且可读取的本地附件。外部地址、不相关附件、无法核验的文件或超预算资源会明确拒绝；服务器不会为导出抓取外部图片。原有导入流程支持的普通 ZIP 保持原语义，不会因为升级自动重建其 ID。

## 格式与保存合同

跨站包的 `markbridge-export.json` 使用 `schema:2`，新增唯一意图字段 `mediaAssociation:"create-new"`；正文和图片摘要、资源列表及描述性元数据仍须完整匹配。包不含旧站数值附件 ID、作者身份、凭据、私人笔记或来源路径；元数据不会因导入自动成为发布指令。

导入在原有私有暂存中验证这个意图，将其绑定到当前站点、用户、正文、图片清单和预览票据。保存阶段创建附件后，PHP／Node 以同一受限转换动作写入服务器刚创建的 URL 与新 ID；失败沿用既有补偿和未知提交保护。读者临时状态不进入副本，来源绑定文章仍不能通过 ZIP 绕开原来源维护。
