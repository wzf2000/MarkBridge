# Static chart bridge sample

Copy this source directory into a development WordPress plugins directory and enable alongside MarkBridge 2.9 and the frozen `small-data-chart@0.0.1` research provider. The trusted PHP renderer declares its actual callback/model files and derives a finite typed SVG, semantic full data table and summary from saved canonical params. It does not save derived content, query a service, add a save endpoint or require server Node.

Normal article preview/Apply/paired save remains required. Default PHP reading, single HTML and Publisher's schema-2 chapter building consume the same bounded tree; original source still forbids raw SVG. Without the bridge/provider, author innerBlocks and safe read-only params remain. This is an SDK bridge example, not the later chart workbench or an independently released scientific extension. Run the main shared projection models and desktop/phone browser fixtures before adoption. License GPL-3.0-or-later.
